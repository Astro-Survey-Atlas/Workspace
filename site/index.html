Astro Survey Atlas / user workspace

Workspace (Atlas)

Workspace is the user-facing interactive data exploration surface in Astro Survey Atlas. It hosts the sky dashboard, local asset registration, connectors, credentials, and task orchestration over user data—while public survey packages come from Assets, and high-throughput remote scans can be delegated to Warehouse.

Product boundary

Taken from the in-repo architecture note. Atlas owns user-side state; it does not become a public survey catalog.

Workspace owns

  • User assets, local survey/release labels, connectors, and access metadata
  • Local scanning and optional remote user scans through Warehouse
  • Its own Elasticsearch search indexes, sky coverage queries, and the viewer
  • User MOC artifacts, scan/task history, and evidence references
  • Deterministic Agent/MCP and workflow runs over user data

Workspace does not own

  • Public survey jobs, public connectors, MOC publication, or a public release catalog
  • Registering a user asset with Assets, or publishing user records back to Assets
  • Warehouse Elasticsearch as a shared database (Workspace ES stays independent)

Ordinary public geometry comes from the immutable Resource Package v3 published by Assets. Fine-grained public region queries, when used, stay server-side and scoped—browsers do not hold Assets credentials.
