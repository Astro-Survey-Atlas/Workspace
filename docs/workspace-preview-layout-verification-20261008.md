## 故障证据与修复

Ingress 记录的 `POST /api/sky/download-plan/preview` 请求（含请求头）为
1,137 bytes，等待 480 秒后返回 504，期间上游没有返回响应头。Ingress 原有
读写超时已是 480 秒；Workspace 和 Elasticsearch 健康、无重启。该证据支持
“长时间未返回响应”，不支持“请求体过大”。原请求正文不可用，不能据此断言
这一次线上请求的全部内部原因。

回归复现了两个问题：慢元数据请求在最终 JSON 返回前可触发代理空闲超时；
请求内使用 `Response.clone()` 缓存后，等待取消重定向正文可能因未读取的 tee
分支而挂起。代理回归修复前返回 504，修复后返回 200，慢来源完成前可以收到
已发现文件。元数据缓存改为有界独立正文，并保留实际响应 URL，重定向目录中的
相对文件链接继续指向真实目标。

预览端点支持 SSE 进度、文件增量、完成和错误事件，每 10 秒发送心跳，关闭代理
缓冲；原 JSON 接口兼容。停止、关闭、切换区域/模板、离开数据生产会取消上游
请求和后续批次，包含 DNS 等不直接接收 AbortSignal 的等待。停止或失败后已发现
文件仅可查看；完整预览校验完成后才能勾选并确认。快照、版本、过期时间、清单
摘要和审批集合校验保留，不新增持久化预览 session，不保存公开反查原始正文。

revision 69 的数据生产顶部 DAG 高 140 px，执行记录占据其余主区域；原有 88 px 列表和
164 px 日志高度限制移除。选择记录或节点可展开日志，也可收起。参数保留在
详情面板；文件预览使用主区域，确认成功后返回执行记录。轮询保留记录选择、
滚动位置和键盘焦点。
